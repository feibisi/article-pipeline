学习 WordPress 开发，官方文档不是唯一的选择。以下资源经过实际使用，按学习阶段排序。

入门阶段推荐 WordPress 官方的开发者手册（developer.wordpress.org）。它覆盖主题开发、插件开发、REST API 的基础内容，免费、权威、持续更新。新手最常见的错误是去看博客教程——博客教程的质量参差不齐，而且 WordPress 每年大版本更新，过时的教程会误导你。官方手册始终保持最新，是唯一不会过时的入门资料。

进阶阶段推荐读核心代码。WordPress 的 wp-includes 目录是整个系统的核心，读懂 option.php、post.php、plugin.php 这几个文件，你就理解了 WordPress 的运作方式。这不是最快的学习方式，但是最扎实的方式。搭配 Query Monitor 插件，你能看到每个页面加载时执行了哪些查询、调用了哪些钩子，把抽象的代码逻辑变成具体的执行过程。
